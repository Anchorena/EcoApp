# EcoApp v2 Web

Aplicación profesional para informes ecocardiográficos.

## Funciones principales

- Procesamiento de PDF de ecógrafos.
- Carga de pacientes y datos del estudio.
- Generación de informe ecocardiográfico.
- Anexo con imágenes/PDF.
- Impresión y descarga local.
- Compatible con Windows, macOS, iPad, iPhone y Android desde navegador moderno.

## Publicación en GitHub Pages

1. Subir todo el contenido de esta carpeta al repositorio.
2. Ir a `Settings` → `Pages`.
3. Elegir `Deploy from a branch`.
4. Branch: `main`.
5. Folder: `/root`.
6. Guardar.

La app quedará disponible en una URL similar a:

`https://anchorena.github.io/EcoApp/`

## Nota

Esta versión no usa `server.js`. Está preparada para funcionar como sitio estático y luego conectarse con Supabase.
