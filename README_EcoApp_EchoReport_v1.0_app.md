# EcoApp EchoReport v1.0 — App

Aplicación local para informes ecocardiográficos.

Cambios principales de esta versión:

- Nombre visible: EcoApp EchoReport v1.0.
- Pie de PDF con marca mínima: EcoApp EchoReport v1.0 by Matias Anchorena.
- Numeración de páginas conservada.
- Logos institucionales independientes del médico informante.
- Médicos, firmas y matrículas conservados.
- Base de importación PDF multi-equipo inicial: Sonoscape/SonoScape, Mindray M8/M9 y ESAOTE MyLab.
